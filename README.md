# Karat Java Interview Prep

A practice-first repository for preparing for Karat coding interviews using Java.

This repository contains my solutions to Karat coding problems, with a focus on building strong problem-solving skills, understanding patterns, and writing clean and efficient Java code.

## Goals

- Solve Karat interview problems consistently
- Improve problem-solving and logical thinking
- Strengthen Java and DSA fundamentals
- Analyze time and space complexity
- Prepare for real-world coding interviews

## Language

- Java

## Approach

I try to solve each problem independently first, then improve the solution by focusing on readability, optimization, and edge cases.

> One problem at a time. One step closer to cracking the interview. 🚀
